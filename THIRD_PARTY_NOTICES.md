# Contributions and dependencies

This repository is a screened export of the new Cerberus Edge interface and integration adapter. It is not a formal clean-room implementation and is not the entire running appliance. No private source history is published.

The live appliance retains Ragnar (Pierre Gode) and Bjorn (infinition) as its sensor/runtime dependencies. Their installed notices and license are retained in `apps/edge/public-v3/notices/RAGNAR-LICENSE.txt`. Ragnar includes supplemental noncommercial terms. The license at this repository root does not grant commercial or redistribution rights to that runtime, and this export does not distribute its container, source, database or image. Competition eligibility and any wider distribution of the appliance remain subject to their applicable terms.

React, Vite, Motion, React Flow, React Markdown, Tabler, Lucide, Electron, aiohttp and other package dependencies retain their own licenses; exact versions are in the lockfile and requirements file. Install from their registries to obtain dependency notices. Kenney Interface Sounds are CC0; the original license is retained under `apps/edge/public-v3/notices`.

Private raster mascots, branding source art and bundled fonts were excluded pending publication-rights verification. Public source uses newly authored vector stand-ins and system fonts. Geographic datasets are excluded from this export; optional geographic views report missing data until an appropriately licensed dataset is supplied. No operational snapshot or real model receipt is included.
